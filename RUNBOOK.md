EXTERNAL DATA PREPARATION

The Knowledge Graph constructor consumes entity files generated by the
external MedJsonify project.

Expected directory:

external/medjsonify/NER/data/entities/

Expected subdirectories:

external/medjsonify/NER/data/entities/xml_files/
external/medjsonify/NER/data/entities/csv_files/
external/medjsonify/NER/data/entities/txt_files/

The input path is configured in:

kg_constructor/configs/config.yaml

Configuration field:

source.medjsonify_entities_dir

Default value:

external/medjsonify/NER/data/entities

If MedJsonify is installed or executed outside this repository, update
`source.medjsonify_entities_dir` to point to the external output directory
before running the Knowledge Graph pipeline.

The MedJsonify environment should be configured from:

external/medjsonify/.env.example

Create the local environment file with:

cp external/medjsonify/.env.example external/medjsonify/.env

Do not commit the resulting `.env` file.

The original RelationPrediction TensorFlow implementation is stored under:

external/relation-prediction/

The main thesis R-GCN implementation remains under:

models/rgcn/

See external/README.md for the purpose, provenance, licensing, and dependency
requirements of both external projects.
