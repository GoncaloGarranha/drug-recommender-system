Aceder ao container airflow_webserver:
"docker exec -it airflow_webserver bash"

docker cp "caminho do ficheiro a copiar" caminho a guardar
por exemplo: docker cp "D:\FacudadeGoncalo\Mestrado\Tese\tese\MedJsonify-main\airflow\dags\jsonify\config\config.ini" airflow_webserver:/opt/airflow/dags/jsonify/config/config.ini

Quando faço alterações nas DAGs ou variáveis:
docker-compose restart airflow
docker-compose restart airflow

Ou reiniciar todos os serviços:
docker-compose down
docker-compose up -d

Listar diretorias ou ficheiros importantes dentro do container
ls -lh /opt/airflow/dags/jsonify/src/json/xml_files | head  # Ver JSON convertidos
ls -lh /opt/airflow/dags/final_output/  # Ver CSV final
ls -lh /opt/airflow/dags/ # Ver todas as DAGs disponíveis

Copiar ficheiros do container para o host
docker cp airflow_webserver:/opt/airflow/dags/final_output/final_dataset.csv "CAMINHO/NO/WINDOWS/final_dataset.csv"
